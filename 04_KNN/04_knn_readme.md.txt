# 📍 K-Nearest Neighbors (KNN)

## 📌 Overview
Instance-based classification using KNN, applied to the breast cancer dataset and a general practice notebook.

## 📂 Files
| File | Description |
|---|---|
| `knn_practie.ipynb` | KNN fundamentals and practice |
| `breast_cancer03.ipynb` | Breast cancer classification using KNN |
| `AI_impack.ipynb` | KNN applied to an AI-impact related dataset |

## 🧠 Concepts Covered
- Distance metrics (Euclidean distance)
- Choosing the right value of K
- Effect of feature scaling on distance-based models
- Bias-variance tradeoff with K

## ▶️ How to Run
Open any notebook in Jupyter and run all cells top to bottom.
