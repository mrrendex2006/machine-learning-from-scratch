# 📊 Datasets & Practice Notebooks

## 📌 Overview
General practice notebooks used to test ML concepts on additional datasets outside the main algorithm-by-algorithm structure above.

## 📂 Files
| File | Description |
|---|---|
| `Coffee_Waste_Physiology_Dataset.ipynb` | Classification/regression practice on a small physiology dataset (note: small sample size, used for learning rather than production-grade results) |
| `iris_dataset_ML.ipynb` | General ML practice on the Iris dataset |
| `ml_learning.ipynb` | Miscellaneous ML concept practice |

## ▶️ How to Run
Open any notebook in Jupyter and run all cells top to bottom.

> **Note:** This folder and `practice datasets/` currently overlap (`iris_dataset_ML.ipynb` appears in both). Consider merging them into a single `practice/` folder to avoid duplication.
