# 📈 Linear Regression

## 📌 Overview
This module covers Linear Regression, applied across several real-world datasets to compare how the algorithm behaves on different kinds of data.

## 🧠 Concepts Covered
- Hypothesis function & cost function
- Gradient descent
- Multi-model comparison (Linear, Ridge, Lasso, Random Forest)
- Evaluation metrics: R², MAE
- Feature scaling (StandardScaler)
- Algorithm selection based on dataset characteristics

## 📂 Files
| File | Description |
|---|---|
| `california_housing.ipynb` | Regression on California housing prices |
| `diamond.ipynb` | Price prediction on the diamonds dataset — model comparison (Linear/Ridge/Lasso/RF) |
| `house_pricing.ipynb` | House price prediction |
| `miles_per_gallon.ipynb` | Predicting fuel efficiency (MPG) |
| `tip_amount.ipynb` | Predicting restaurant tip amount |
| `tip_using_rf.ipynb` | Same tip prediction problem, solved with Random Forest for comparison |

## ▶️ How to Run
Open any notebook in Jupyter and run all cells top to bottom. Start with `diamond.ipynb` if you want to see the multi-model comparison first.
