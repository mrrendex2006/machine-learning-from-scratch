# 📊 Logistic Regression

## 📌 Overview
Classification using Logistic Regression, applied across several real-world and toy datasets to see how the algorithm performs on different kinds of classification problems (binary and multi-class).

## 📂 Files
| File | Description |
|---|---|
| `breast_dataset/breast_cancer01.ipynb` | Binary classification on the sklearn breast cancer dataset |
| `iris_dataset/iris_dataset.ipynb` | Multi-class classification on the Iris dataset |
| `AI impact/AI_impack01.ipynb` | Logistic regression applied to an AI-impact-on-jobs/layoff-risk dataset |
| `coffee_dataset/Coffee_Waste_Physiology_Dataset.ipynb` | Multi-class classification (label-encoded treatment groups) on a coffee waste physiology dataset |
| `telescope_ml/telescope_ml01.ipynb` | Binary classification on the MAGIC gamma telescope dataset, with class imbalance handling |

## 🧠 Concepts Covered
- Sigmoid function & decision boundary
- Binary vs. multi-class classification
- Label encoding of categorical targets
- Handling class imbalance (oversampling)
- Feature scaling (StandardScaler)
- Model evaluation on classification tasks

## ▶️ How to Run
Open any notebook in Jupyter and run all cells top to bottom. Start with `breast_dataset/breast_cancer01.ipynb` for the simplest binary classification example.
