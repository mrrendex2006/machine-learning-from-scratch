# 🌲 Random Forest

## 📌 Overview
Ensemble learning using Random Forest, building on the single decision tree module to show how bagging multiple trees improves performance.

## 📂 Files
| File | Description |
|---|---|
| `AI_impack.ipynb` | Random forest applied to an AI-impact related dataset |

## 🧠 Concepts Covered
- Bagging & ensemble learning
- Feature importance
- Comparing a single decision tree vs. a random forest
- Reducing overfitting through averaging

## ▶️ How to Run
Open the notebook in Jupyter and run all cells top to bottom.
