# 🧮 Support Vector Machine

## 📌 Overview
Classification using Support Vector Machines, continuing the breast cancer classification problem introduced in earlier modules for direct comparison against logistic regression and KNN.

## 📂 Files
| File | Description |
|---|---|
| `breast_cancer02.ipynb` | Breast cancer classification using SVM |

## 🧠 Concepts Covered
- Margin maximization & support vectors
- Kernel trick (linear vs. non-linear boundaries)
- Hyperparameters: C, gamma
- Comparing SVM accuracy against logistic regression on the same dataset

## ▶️ How to Run
Open the notebook in Jupyter and run all cells top to bottom.
