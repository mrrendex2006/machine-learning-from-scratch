# 🌳 Decision Tree

## 📌 Overview
Classification using Decision Trees on the classic Iris dataset, with a visual diagram of the resulting tree structure.

## 📂 Files
| File | Description |
|---|---|
| `iris_dataset.ipynb` | Decision tree classification on the Iris dataset |
| `desion_tree.png` | Visualization of the trained decision tree |
| `AI_impack.ipynb` | Decision tree applied to an AI-impact related dataset |

## 🧠 Concepts Covered
- Entropy & Gini impurity
- Information gain
- Tree depth & overfitting
- Visualizing decision boundaries and tree structure

## ▶️ How to Run
Open any notebook in Jupyter and run all cells top to bottom. Check `desion_tree.png` after running `iris_dataset.ipynb` to see the visualized tree.
